## 1. 压测概述
### 1.1 压测目的
1. 验证服务在高并发场景下的性能表现与稳定性，核心指标满足业务SLA要求
2. 验证JDK 21 分代ZGC配置在压测下的停顿表现与内存稳定性
3. 验证全链路TraceId在同步、异步、高并发场景下的正确性，无串号、无丢失
4. 定位性能瓶颈，输出调优方案，为生产环境配置提供数据依据

### 1.2 压测场景覆盖
| 场景编号 | 场景描述         | 压测接口               | 验证目标                     |
| -------- | ---------------- | ---------------------- | ---------------------------- |
| S1       | 同步接口基准压测 | `/test/trace/sync`     | 核心接口吞吐与延迟能力       |
| S2       | 异步接口压测     | `/test/trace/async`    | 异步线程池性能与上下文传递   |
| S3       | TraceId透传验证  | `/test/trace/transmit` | 上游链路ID透传一致性         |
| S4       | 异常场景稳定性   | `/test/trace/error`    | 异常下服务稳定性与日志完整性 |
| S5       | 长时稳定性压测   | 同步接口持续10分钟     | 内存泄漏、GC漂移、长稳表现   |

### 1.3 验收基准
| 指标大类 | 指标项           | 合格标准 | 优秀标准 |
| -------- | ---------------- | -------- | -------- |
| 业务性能 | 接口错误率       | ≤ 0.1%   | 0%       |
| 业务性能 | P99 响应时间     | ≤ 200ms  | ≤ 100ms  |
