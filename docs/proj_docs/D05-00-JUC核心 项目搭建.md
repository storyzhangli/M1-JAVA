### 线程池参数（按当前机器 CPU 核数动态计算）

| 参数             | 值                 | 说明               |
| ---------------- | ------------------ | ------------------ |
| corePoolSize     | CPU核数 × 2        | 混合 IO/CPU 负载   |
| maxPoolSize      | CPU核数 × 4        | 队列满后扩容上限   |
| queueCapacity    | 200                | 有界队列，防 OOM   |
| keepAliveSeconds | 60                 | 非核心线程回收     |
| threadNamePrefix | `biz-async-`       | 日志/jstack 可定位 |
| rejectedPolicy   | CallerRunsPolicy   | 背压，不丢任务     |
| shutdown         | 优雅关闭，等待 30s | 应用停机不丢任务   |

### 关键坑点
- `@Async` 方法必须 `public`，且不能被同类内部方法直接调用（Spring AOP 代理失效）
- 默认 `SimpleAsyncTaskExecutor` 不复用线程，生产环境必须替换为自定义 `ThreadPoolTaskExecutor`
- 队列必须有界，无界队列在流量洪峰下会 OOM
