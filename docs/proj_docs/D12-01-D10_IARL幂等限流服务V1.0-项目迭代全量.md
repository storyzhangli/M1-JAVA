## 1. 项目背景、目标与功能范围

### 1.1 背景

`D10_IARL` 是 M1-Java 学习工程 D10 阶段的核心模块，围绕高并发后端最常见的两类稳定性问题展开：

- **接口幂等（Idempotency）**：同一操作因网络重试、用户重复点击、消息重投被执行多次时，业务只能生效一次。
- **限流（Rate Limiting）**：在流量超过系统承载能力时，按维度快速拒绝超额请求，保护下游资源。

在实现这两个主线能力的同时，模块沉淀了一套可复用的工程基座：统一返回与全局异常、Redis 缓存与缓存三大问题治理、Redisson 分布式锁、异步线程池与 `traceId` 链路追踪、Token 登录拦截、Knife4j 接口文档、Nacos 服务注册。

### 1.2 目标

1. 以注解 + AOP（Aspect-Oriented Programming，面向切面编程）+ Redis Lua 的方式，提供可复用、线程安全的幂等与限流能力。
2. 覆盖认证、缓存、分布式锁、异步并发、链路追踪等真实后端常见场景，形成可运行、可演示、可压测的单体服务。
3. 所有关键能力均有对应 HTTP 端点与验证脚本支撑，而非仅停留在工具类层面。

## 3. 核心业务流程概览

> 本章只做现状索引，原理、时序图与实操见 D12-02。

1. **请求入口与链路**：`TraceIdFilter`（最高优先级 `OncePerRequestFilter`）接收或生成 `X-Trace-Id`，写入 MDC（Mapped Diagnostic Context，映射诊断上下文）并回写响应头，`finally` 清理。
2. **鉴权**：`AuthInterceptor` 校验 `Authorization` 头对应的 Redis token，续期 2 小时并写入 `UserContext`（ThreadLocal），`afterCompletion` 清理；登录/注册/文档/幂等/限流演示路径在 `WebConfig` 放行。
3. **业务处理**：Controller → Service → Mapper/Redis；幂等与限流通过注解切面在方法前后织入。
4. **异步分支**：`@Async` 方法进入 `bizTaskExecutor` 线程池，`MdcTaskDecorator` 在提交时复制 MDC、执行后还原，避免线程池复用串号。
5. **出口**：正常返回统一 `Result`；业务异常由 `GlobalExceptionHandler` 转换为错误码，限流异常转换为 HTTP 429 并带 `Retry-After`。

## 6. 数据库初始化（重要边界，如实说明）

- **本模块不提供任何建表 SQL**：`D10_IARL` 目录下 `.sql` 文件数量为 0，也没有 MyBatis mapper XML（持久化全部依赖 MyBatis-Plus `BaseMapper` 内置方法）。
- 实体与数据表的映射来自 `@TableName` 注解，运行前需确保 `ai_db` 中已存在这些表（表结构由更早阶段的 RBAC/缓存课程预置，不在本模块交付物内）：

| 实体 | 表名 | 主要字段（源码） |
|---|---|---|
| `SysUser` | `sys_user` | id、username、password、nickname、phone、status、create_time、update_time |
| `User` | `t_user` | id、username、phone |
| `SysRole` | `sys_role` | 角色实体（本模块无对应 Controller 暴露） |
| `SysPermission` | `sys_permission` | 权限实体（本模块无对应 Controller 暴露） |

- 初始化前置步骤：
  1. 启动 MySQL，创建库：`CREATE DATABASE IF NOT EXISTS ai_db DEFAULT CHARACTER SET utf8mb4;`
  2. 按历史阶段脚本创建 `sys_user`、`t_user` 等表并准备至少一条用户数据（注册接口也可写入 BCrypt 密码的新用户）。
- 幂等、限流、锁、token **不依赖数据库表**，全部基于 Redis；数据库仅用于登录/注册与用户缓存回源。

## 9. 异常处理与错误码

### 9.1 全局异常处理策略（`GlobalExceptionHandler`）

| 异常 | 处理 | HTTP 状态 |
|---|---|---|
| `BusinessException` | `Result.fail(code,msg)`，记录 warn | 200（看 body.code） |
| `RateLimitException` | 带 `Retry-After` 响应头 | **429 Too Many Requests** |
| 兜底 `Exception` | 记录完整堆栈，返回“服务器内部异常” | 200（body.code=500） |
| 未登录/ token 失效 | `AuthInterceptor` 直接写 JSON | 401 |

### 9.2 错误码表（`ResultCodeEnum` 及实际使用）

| code | 枚举/含义 | 触发位置 |
|---|---|---|
| 200 | SUCCESS 成功 | 正常返回 |
| 1001 | PARAM_ERROR 参数错误（幂等缺键/异参复用也使用该层） | 幂等切面、参数校验 |
| 2001 | BUSINESS_ERROR 业务处理失败（幂等处理中/状态过期使用该层） | 业务异常默认 |
| 2002 | LOCK_INTERRUPTED 缓存锁中断 | 锁等待被中断 |
| 2003 | CACHE_BUSY 缓存重建繁忙 | 防击穿重试耗尽 |
| 2004 | LOCK_ACQUIRE_FAILED 获取锁失败 | 加锁超时 |
| 3001 | SYSTEM_ERROR 系统异常 | 预留 |
| 4001 | NO_PERMISSION 无权限 | 预留 |
| 401 / 404 / 429 / 500 | 登录失效 / 用户不存在 / 限流 / 内部错误 | 拦截器与全局处理 |

以下为**历史真实执行并记录**的结果，本轮未重复，引用而非新造：

### 10.3 验证脚本现状（`script/verify_demo.ps1`）

脚本覆盖幂等五场景与限流 B1～B5。**需注意其 B2/B5 场景的预期注释停留在整改前**：脚本假设携带 `X-Forwarded-For` 即可获得独立桶，但整改后默认 `trust-forward-headers=false`，本机回环虽在白名单内，仍需满足代理跳数规则；因此脚本中“XFF 独立桶”的预期文字与现行安全策略不完全一致，运行时应以 D10-08 的实测口径为准（见第 11 章已知问题）。

## 13. 附录

### 13.1 记忆简语

> **一统二防三注解，锁池串号四条线。**
> 一统：统一 Result 与全局异常；二防：缓存防击穿/穿透/雪崩 + 限流防伪造；三注解：@Idempotent、@RateLimit、@Async；锁：Redisson 固定租约与看门狗；池：有界线程池+背压；串号：MDC 装饰器清理防 traceId 串号。

### 13.2 竖屏层级树

```
D10_IARL（8080 / d10-iarl）
├─ 入口
│  ├─ TraceIdFilter（X-Trace-Id → MDC → finally clear）
│  └─ AuthInterceptor（Redis token → UserContext → afterCompletion clear）
├─ 公共
│  ├─ Result / GlobalExceptionHandler（429 + Retry-After）
│  └─ ResultCodeEnum（1xxx/2xxx/3xxx/4xxx）
├─ 数据
│  ├─ MySQL(ai_db) ← MyBatis-Plus BaseMapper（无 XML）
│  └─ Redis 6.2.12（token/缓存/锁/幂等/限流）
├─ 能力
│  ├─ 缓存：Cache-Aside + Redisson 锁(DCL/空值/随机TTL)
│  ├─ 锁：固定租约 / 看门狗，模板自动释放
│  ├─ 异步：bizTaskExecutor + MdcTaskDecorator
│  ├─ 幂等：注解 + Lua + ownerToken + 作用域键
│  └─ 限流：注解 + 令牌桶 Lua + IP/USER/BUSINESS
└─ 运维：Nacos 注册 / Knife4j / jvm.options / bin+script / logs
```

### 13.3 Redis Key 速查

| 用途 | Key 模式 | TTL |
|---|---|---|
| 登录 token | `auth:token:{token}` | 2h |
| 手动用户缓存 | `d04:user:info:{id}` | 10m |
| 系统用户缓存 | `sys:user:{id}` | 30m + 0~5m 随机 |
| 缓存重建锁 | `lock:sys:user:{id}` | 固定租约 30s |
| 库存/锁 | `stock:sku:{skuId}` / `lock:stock:{skuId}` | 业务控制 |
| 幂等记录 | `idempotent:{租户}:{类#方法}:{幂等键}` | 默认 300s |
| 限流桶 | `ratelimit:{维度}:{维度值}:tokens` / `:timestamp` | 桶填满时间×2 |
